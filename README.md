# 沙畫效果｜單圖中央・非同步散逸版

## 本版調整
- 每次載入只會從 `pic/` 中隨機抽取 1 張圖片。
- 圖片固定置於畫面正中央。
- 粒子仍會隨機從左側或右側進場。
- 散開時每顆粒子獨立隨機往左或右離開。
- 粒子分為 fast / normal / slow 三種速度，離場時間不再同步。
- 約三分之一粒子帶較明顯柔化與暈散，散出時暈光會逐漸變大。
- 外圍粒子略早鬆散，中心輪廓會多停留一些，接近參考 GIF 的風化感。
- 粒子顏色仍以 `#FF6B6B` 為主，只使用同色系亮暗變化。
- body 無文字。

## 可調整參數
位置：`js/canvas.js`

- `IMAGE_DURATION = 10.5`：整段動畫秒數。
- `TARGET_MAX_WIDTH = 430`：圖片最大寬度。
- `TARGET_MAX_HEIGHT_RATIO = 0.72`：圖片最大高度占畫面比例。
- `DUST_COUNT = 45`：背景淡砂塵數量。
- `const gap = 2`：圖片粒子取樣密度；數字越小粒子越密、效能需求越高。
- `this.isSoft = Math.random() < 0.34`：柔化粒子比例，目前約 34%。
- fast / normal / slow 的比例與 `exitStart`、`exitSpan` 可控制散逸速度差異。

直接用瀏覽器開啟 `index.html` 即可檢視。
